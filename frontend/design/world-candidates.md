# 视觉世界候选清单（第三步 · 方向掷骰记录）

> 2026-10-15 · D 前端重设计 · 工具链：impeccable concept-seed（key: b85af2c4）
> 规则：方向只贡献 **字体 / 配色 / 密度 / 一个标志性动作**；导航与控件一律用标准件（Operate 模式限定）。

## 我的七个自推候选（按共鸣度排序）

1. **总账本**（中式总账 / 账房）· 纸墨账簿 —— 产品的脊柱就是"每一分钱可追"，账簿天生承载金额与恒等校验（收付存）。
2. **审计工作底稿**（底稿装订 / 索引号 / 编制-复核双签）· 档案装订 —— "第三人复现"本身就是审计动作；索引体系天然解决导航。
3. **化验单**（检验报告 / 参考区间 / H-L 旗标）· 临床表单 —— 核验状态天然对应化验旗标；"样本"一语双关。
4. **信证与用印**（劳合社承保条 / 批单 / 验讫章）· 印章仪式 —— 保险语境的原生仪式：用印 = 权威与核验的诚实语言。★ 指派
5. **监管统计公报**（红头猫头鹰体/三线表/口径脚注）· 官方出版物 —— B0/B1 统计表的天然归宿。
6. **列车时刻表**（计划/实际两列 / 翻牌更新）· 交通印刷 —— 事件流 = 时刻行；"计划 vs 实际"对应义务与执行。
7. **档案目录卡**（三色卡口 / 抽屉索引）· 木柜卡片 —— 运行目录与来源色标。

（品类常规陷阱：深色/浅色"评测控制台"与它的反面"渐变大字营销页"——均不入列。）

## 掷骰结果

- **指派（THE ROLL）：第 4 位「信证与用印」**（脚本指定自推列表第 4 项，用于打破排名惯性）。
- **IMPECCABLE'S PICK（我的头号）：第 1 位「总账本」**——附诚实风险行（熟悉感）。

## 目录种子发下的 6 张挑战者（融合本产品后称重）

| 挑战者 | 判定 | 说明 |
|---|---|---|
| 深色控制台（graphite / 发丝缝 / 语法色） | competitive | 融合干净；与品类惯性同形是代价 |
| 机场导视（黄黑 / 边缘规则 / 距离分钟） | competitive | 把"怎么走"讲得最清楚；强度需克制 |
| 星图星表（深夜蓝 / 量级点阵 / 坐标网格） | competitive | 量级编码天然；与保险语境的疏离是代价 |
| 短视频信息流 | declined | 全屏单件与专业数据阅读互斥 → 捐"运行封套" |
| 磁带 J 卡 | declined | 手写体承载精确金额吃亏 → 捐"蓝笔批注" |
| 可变字体样本页 | declined | 是字体的世界不是钱的世界 → 捐"巨微对比" |

## 对指派方向的三条"捐赠升级"（raised）

1. 运行封套（from 短视频信息流）：当前运行围成一个完整对象，切换硬切替换。
2. 蓝笔批注（from 磁带 J 卡）：人工批注用蓝笔手写体；机器事实一律印刷体。
3. 巨微对比（from 可变字体样本页）：核心数字展示级字号压住微型标签。
