# AgentShield V1.1 施工文档包

## 先读什么

`AgentShield_v1.1_Plan.docx` 是适合团队阅读和讨论的主文档；同名 `.md` 内容一致，适合交给编码 AI。
`role_cards/` 中四份 Markdown 可分别发给 A/B/C/D；任务卡须结合主文档共同红线、接口和验收使用。
`delivery_levels_v1.1.json` 是完成级别的机器可读规格，所有验收状态均为 not_checked。

## 文档不是已完成系统

此包没有实现沙箱、Agent 或保险引擎，没有调用收费 API，没有运行项目业务验收，也没有更新旧包中的实际 contracts。计数、分工、日程和验收均为设计规范。本文版本覆盖旧 V1.0 的完成级别、分工与日程；技术接口实物仍需按主文档第 24 节迁移。

## 统一门槛

L0：工程连通，不是最终成果。
L1：一个真实 Agent 与规则基线的完整对照，24 个常规任务＋4 个压力任务；56 次真实运行与 28 次规则运行分开记。
L2：两真实配置，48＋12 个任务；240 次真实运行，规则基线另 60 次。
L3：可选增强，上限计划 96＋24 个任务、720 次真实运行，规则基线另 120 次；高级统计须独立满足条件。

所有数量都是工程设定，不证明真实事故率、定价充分性或获奖水平。J3 只代表 L1 发布候选；正式完成还需 J4 发布验收。项目排期使用北京时间（UTC+8）。
