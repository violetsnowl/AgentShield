# 决策：IA v3 三页信息架构（导航 / 单一运行选择器 / 深链接 / 护栏）

状态：D 线已实装（2026-10-15，待 A/C 复核）· 范围：前端信息架构层；不改 B/C/A 权威后端逻辑与既有数据。

## 背景

四区工作台改为面向评委与首次使用者的三阶段流程：**Agent 测试 → 风险评估 → 保险方案**，目标是五秒内知道下一步该做什么；视觉主题沿用原导视系统。

## 决策

1. **三页命名与 URL**：`test` / `risk` / `insurance`（`#area=`）。旧值兼容：`lab`→test、`evidence`→test 且自动展开详细执行证据、`risk`→risk、`cost`→insurance；`run=` 语义不变。
2. **单一运行选择器**：顶部唯一 `#run`，内部分两组——「本机会话」`case_id ｜ session_id`、「已交付历史运行」`真实模型/Mock · 标签 ｜ …末8`。旧 `#integration-run` 已删除；「查看已有运行」仅为辅助入口（定位运行条并展开筛选），不产生第二个选择状态。
3. **运行↔结果严格绑定**：单次核验与理算面板仅在所选运行于交付目录中有精确 session 对应时显示；无对应时结果卡显式显示「暂无核验结果 / 暂无理算结果」，**绝不显示其他运行的核验或赔款数字**。选择仅存在于交付目录的运行（本机会话无对应）时，自动跳到 Agent 测试并展开详细执行证据，`← 返回上一位置` 可回到原页面。
4. **页职能**：页1 = 单次输入/执行/结果（开始测试卡四步 + 结果卡 + 核验面板 + 折叠的详细执行证据）；页2 = 跨运行汇总（每项标注 `[范围｜开发｜样本 N]`，含「来源运行」折叠；核验状态 / 任务升级 / 人工工单为相互独立维度）；页3 = A4 两套研究候选产品卡（Core / Plus，null 参数一律「待定」，附「测算依据」与分离标注的单事件理算工程示例）。
5. **默认折叠**：运行详情与详细执行证据默认不展开；技术 ID / 版本 / 哈希 / 原始 JSON 不进入默认视图。
6. **出口牌三站**：页内容末尾 `‹ 回看 / 前往下一站`；第Ⅲ页收尾为「走完了 · 回到 Ⅰ Agent 测试」。
7. **新护栏**（核心浏览器套件）：IA3-01 出口牌三站推进（全程所选运行不变）；IA3-02 legacy 深链接（evidence 冷启动自动展开证据区）；IA3-03 默认无长 ID / 无原始 JSON、详情默认折叠；IA3-04 交付运行全链路绑定、切换无残留。

## 不变量（未变）

- 不虚构保费/损失/赔款；不自动执行 Agent（「启动 Agent」禁用并随按钮说明原因）；浏览器不持有管理员令牌；不访问私有 Gold。
- 资金金额、null/0、期初与历史退款、只读权限、交易追溯、回放等行为断言不删减——只改进入路径/定位/步骤；测试迁移中若某处无法两全则回退该项并报告，不以删断言换全绿。
- 旧启动回归脚本（`check_startup.py` / `check_startup.mjs`）修复后保留，不先删除。

## 影响与验证

- 测试迁移：核心 741 项与 stage04 117 项中仅约 6% 涉及导航/进入路径需改；资金、隐私、网络不变式断言不受影响（browser 625 + stage04 64 + bcp2 14）。
- 验收材料：迁移后全量电池（11 项）与三页实际截图；最终提交与验收状态以交付批为准。
