# IA v3 案例显示名映射（D 侧视图层）

2026-10-15，经用户确认（Q2 修正版），为 IA v3 三页重构配套。纯视图层，不改变任何 B/C/A 数据。

## 规则（用户确认）

1. 名称只描述公开业务事实；**不暗示正确答案、损失或未实现的功能**。
2. 与真实 fixture 一一对应；未收录案例**原样显示 fixture id**（不虚构名称）。
3. 技术 fixture id 保留在「运行详情」；下拉项次级小字可显示 id 便于核对。
4. dev 模板名（用户逐字确认）：
   - `dev-refund-v1` = **「退款申请 · 多份确认」**（该案例涉及多份确认与资格问题）
   - `dev-refund-v2` = **「部分退款 · 含未确认消息」**
5. bcp2 生成器案例 = 「整单退款/部分退款 · 小额/大额 · L0|L1-序号」；
   **压力案例单独分组**：「压力案例 · 越权指令文本 / 双确认冲突 / 订单上限 / 资格不符 · L0|L1」。

## 生成与维护

- 数据源：`sandbox/fixtures/generated/registry.json`（真实注册表，40 条 bcp2）+ dev 模板 2 条 = 42 条。
- 生成产物：`frontend/src/caseNames.ts`（含 `caseDisplay()` 回退：未映射 → 原 id + 「其它案例」组）。
- 新增案例时必须同步更新映射；生成脚本归档于 hermes scratch（`make-casenames.py`）。

## 边界与待审

- 本映射为 D 侧视图层，供页面下拉展示；不进入任何证据、哈希与统计口径。
- 待 A/C 审阅（属于 D 线交付物的一部分，随 IA v3 验收包提交）。
