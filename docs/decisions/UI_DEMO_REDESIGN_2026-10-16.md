## 1. 规范豁免（覆盖了什么）

- 不再以 `AgentShield_v1.2_Plan.md` §16「完整可操作工作台」的前端展示方向与 §26 的信息分布/UI 功能要求为本轮约束（计划书本身**未修改**，避免影响全队基线）。
- N01–N16 验收矩阵不再理解为必须原样保留全部前端操作入口；改为按 A/B/C 三类处理（见 §4 测试映射）。
- 完全取消移动端（390px）专门适配与视觉验收；本轮仅以桌面端为目标（1366×768 / 1440×900）。
- 推翻旧视觉契约（机场导视落地件）：删除常驻灰色运行条、黑色底部出口牌、粗黑框面板与黑底栏目头。设计记录 `DESIGN.md` 顶部已加状态注记（被本轮取代，保留作历史）。

## 3. 保留的正确性底线（不豁免，且已被测试覆盖）

- 金额语义：已提交退款＝B 资金事实；退款≠净损失；净损失 `null` 显示「未知」，`0` 限定范围；期初历史不计入本轮。
- 运行↔结果严格绑定：核验/理算数字仅来自与所选运行精确匹配的交付条目；无对应时显式「暂无核验结果 / 暂无理算结果」，绝不显示其他运行的数字。
- 来源区分：真实模型 / Mock / 规则基线 / 回放 / 开发运行不混称；开发运行处处标注「不计入 56 次」。
- 诚实元素保留可见：任务升级≠核验待审、人工工单为独立维度、A0 工程示例与 Core/Plus 分离（“A0 工程理算示例，不代表 Core / Plus 产品报价”）、`commercial_quote=false` 等。
- 只读边界：观察者仅只读；浏览器不持管理员令牌；离线回放零网络请求；回放不触发任何执行或资金写操作。
- 竞态与状态机：运行切换的迟到响应不能覆盖新选择（核心套件 + stage04 F03 九项竞态复测全过）；加载中不显示旧运行事实；错误态不清空成旧数据混合快照。
- 安全性：一次性授权不入 URL 留存、无 JS 可读凭据、响应/请求/构建物秘密扫描、未授权上下文不可读任何运行。

## 4. 测试映射（A 保留 / B 改写 / C 退役）

**A 类（原样保留断言，仅改进入路径）**：金额恒等与展示（333¢/250¢/期初历史）、运行↔结果绑定、null≠0、来源不混称的 T1–T3、legacy schema 1/2 不补造、回放边界（F03 六变异拒绝、File.text 乱序、迟到目录）、鉴权与秘密扫描、零外网请求、`#run` option 结构、运行详情含精确 session/episode。

**B 类（按新 UI 重写定位）**：导航改用 `01 测试案例 / 02 风险结论 / 03 保险方案` 链接；「保存证据回放 / 创建业务会话 / 刷新本次运行」经由页脚「开发工具」；核验面板改为折叠（先展开再断言可见性/按钮）；结果读数容器 `.result-cards → .run-result`；风险页断言改用 `textContent`（审计折叠内容也计入）；事件改全量加载（去分页按钮后直接等待全部行）；N04「返回上一位置」链路保留。

**C 类（退役并记录原因）**：
| 退役项 | 原因 |
|---|---|
| 「启动 Agent」禁用按钮及其断言 | 提示词要求删除灰置按钮避免误读；诚实说明改由开发工具注记（“运行接口接通前不存在”）与来源标签承担 |
| 运行条默认收起/展开、「切换运行」、`openRunBar` | 常驻灰色运行条被删除，选择器常驻顶栏 |
| 运行筛选、加载更多运行 | 提示词列为可删除的旧工作台能力 |
| 事件状态筛选、事件分页 | 同上；事件改为一次加载（≤100 条），排序/零金额语义以更直接的断言保留 |
| 复制运行身份 | 提示词列为可删除；运行详情仍可通过「运行详情」折叠查看/选取 |
| 移动端 390px 截图与断言 | 本轮仅桌面端（提示词 §7） |
| 出口牌三站推进断言 | 出口牌被删除；改验「下一步/上一步/回到第一步」文字链接的三步回环，运行不变语义保留 |
| 旧批A/N16 中 `.execution-bar` 断言 | 保留（该元素确认不存在）；`.identity-extra` 断言保留（来源标签仍单点收拢于运行详情折叠） |
