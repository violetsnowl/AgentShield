# 年度引擎独立蒙特卡洛核对 V0.1

本文件由 `experiments/verify_annual.py` 生成。数字以同名 JSON 为准。

## 结论

- 共比较 39 项。差值在 3 个标准误以内的有 39 项。
- 超过 3 个标准误的项：无。
- 扣掉格点差（引擎 50 元格点对 10 元格点）后，仍超过 3 个标准误的项：无。
- 模拟 4,000,000 个年度，种子 20261108，用时 200 秒。

## 方法

引擎用 50 元格点和 Panjer 递推算年度损失分布。核对不用这条路。

- 普通事故数 N 取泊松分布，均值 λ。
- 每起事故的金额，直接从 69 个真实严重度金额里按权重抽。不做格点。
- 抽 N 之后，把 N 起事故按权重分到各个金额上（多项分布）。这和逐起独立抽同分布。D 类 λ 约 1373，逐起抽要上百亿次，所以用多项分布。脚本留了 `ordinary="per_event"` 逐起抽的写法，可对照。
- 每个批量事故按自己的原子独立抽。一年最多发生一次。没抽中任何原子，就没有这个事故。
- 年度总损失 L = 普通损失 + 批量损失。
- 8 个格子（A、B、C、D 各分无监测、有监测）各用独立的随机流。流由 `SeedSequence(种子).spawn(8)` 按格子顺序生成。
- 每个格子分 40 批，每批 100,000 年，分批生成，内存只占一批。

标准误怎么算：

- 均值、概率：用逐年样本的标准差除以根号年数。
- P99、CTE99：每批各算一次，取 40 个批估计值的标准差，除以根号批数。
- 差值 = 引擎值 − 模拟值。差值的绝对值不超过 3 个标准误，记为“3 倍内”。

投保后年支出 = 引擎保费 + L − 赔款。保费直接取引擎 `evaluate` 给出的值，两边用同一个数。

## CTE99 在离散分布上的定义

分布是离散的，99% 点上往往有一块概率质量。`tail_stats` 的做法：

- P99 取累计概率第一次达到 99% 的那个值。
- CTE99 是最差 1% 概率上的平均损失。99% 点上的质量只取落在最差 1% 里的那一部分，其余留在 99% 之内。

模拟侧每个年度概率相同，各为 1/n。排序后，P99 取第 ceil(0.99n) 个值。CTE99 取最大的 n/100 个值的平均。n/100 不是整数时，边界上的那个值按比例拆分。这和 `tail_stats` 一致。

## 误差表

单位是元，概率和次数除外。“格点差”是引擎 50 元格点值减 10 元格点值。它是离散化造成的系统差，不是抽样误差。“扣格点差后”是 10 元格点引擎值与模拟值之差，除以同一个标准误。

## 说明

- “精确”只针对离散化后的模型。引擎在 50 元格点上做保均值离散，批量金额四舍五入到格点，时延用四点近似。这三处各有误差，不在“精确”之内。
- 本核对的模拟侧不做格点，能看出前两处。时延四点近似是模型本身的设定，模拟侧用同样的四点，所以这一处看不出来。
- 4,000,000 年是模拟的年度数，不是业务经验。参数是研究假设，不是真实经营数据。
- 3 倍标准误只约束抽样误差。全表 39 项，逐项检验。若引擎和模拟都对，偶尔有一项落在 3 倍外并不奇怪。要看是否成片、是否有方向。

```

```
